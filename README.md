# Interface inspirada no Spotify

Página de estudo de frontend inspirada na apresentação visual do Spotify.

## 📌 Funcionalidades

- Seção de apresentação.
- Cards de recursos e planos.
- Estilização com CSS e imagens.

## Tecnologias

HTML, CSS e Google Fonts.

## 🚀 Como executar

```bash
git clone https://github.com/daviddevdias/web-spotify-clone.git
cd web-spotify-clone

```

Abra `index.html` no navegador. O projeto é uma interface estática para aprendizado, sem reprodução de músicas ou processamento de assinaturas.
